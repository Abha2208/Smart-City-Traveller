# Smart City Traveller 

## Project Description
This project helps users explore cities by showing:
- Tourist Places
- Food Joints
- Shopping Areas
- Fun & Adventure Spots

##  Technologies Used
- Java (Swing / JavaFX)
- MySQL Database

##  How to Run
1. Open project in IntelliJ
2. Run LoginPage.java
3. Enter city → explore categories
